OBSERVATIONS AND REFINEMENTS

1. Row structure recovers six baseline misses without guessing from a previous frame: Laudera Soul 100,
   Demolidores Soul 48, Blake Capacity 1039, Daralion Capacity 1433, Keasol Mana 4112 and Fearless HP 2116.
   The generated safety suite caught an initial defect: a false divider allowed a suffix 1111 from
   seven visible 1s. The fix requires an actual divider transition through each row AND its margins.
   Initial failures are preserved in the initial JSON; the corrected run retains all six gains.
2. Native glyph fitting is useful as an independent shape model, but the complete corpus does not
   justify promoting it for extra recall. Strong model ambiguity vetoes the fallback's correct Quintera
   HP 938. Pixel inspection found complete strokes with two extra pixels on the 8, no missing strokes, no
   remote ink and no clipping: this is model ambiguity, not evidence that the screenshot is obscured.
   A real spacing bug was fixed: round(relative advance)+origin is invariant to one-pixel ROI moves.
   Three translation tests pass; confidence/margin thresholds were not relaxed for a known answer.
3. Cache hits reduce repeated identical-image work, but a changing game background triggers C's
   extra duplicate-panel scan. Its cost is measured separately; static cache speed is not live-video
   throughput. C alone did not clear the final run's predeclared 10% paired timing-benefit gate and
   adds no recovered fields. A+C qualifies through A's coverage gains and its current-frame guards.
   The guard detects translated copies at the established scale/font; arbitrary differently
   scaled/fonted duplicate panels still require broader discovery.
4. The existing robust numeric backend keeps conservative threshold-consensus recovery. Focused
   autonomous development tests recovered BJEI HP 2992 and Deleted HP 4799, Mana 3216 and Capacity 2755
   with A+C. That result was elevated to the separate complete 81-image three-way comparison above.
   The fast recommendation retains every fast-baseline correct field, but gives up these four slow
   numeric recoveries. The robust combination retains both sets of gains and is unsuitable for the
   strict 50 ms gate on this evidence. Gladera is the case that exceeds the budget.
   Four brightness retries multiply the existing bounded touching-digit partition search. The
   glyph cache follows normalization/hole detection, so that preparation still repeats. A future
   optimization could reuse per-frame masks/intervals and cap retry work, returning N/A if unfinished;
   this was not implemented or counted as an evaluated improvement.

VALIDATION AND INTERPRETATION

Repository CI passes on Windows/Ubuntu and Python 3.10/3.12. Verified Python 3.12 logs show
Windows: 914 passed / 3 skipped; Ubuntu: 885 passed / 32 skipped. Lint and compile checks pass.
The full factorial uses 18 Windows shards; the robust comparison uses 12. All variants on a shard
share its host, with rotated execution order. Installed native font provenance/rendering is verified.
Each detected image has 50 static reads, 50 new-Frame reads of identical pixels and 20 generated
outside-panel one-pixel-change diagnostics. Generated diagnostics are never counted as original accuracy.
Every-image p95 must be <=50 ms; pooled p95 alone is insufficient. This is an empirical p95 gate,
not a hard deadline. Raw maximum timings and every per-image sample are retained in artifacts.
Selected initialization p95: 50.28ms; full discovery p95: 13577.11ms;
first read after discovery p95: 14.12ms.
Font preparation is recorded separately; shared font caches may already be warm, so these are not
fully cold process-start measurements. Discovery remains seconds long and belongs outside the steady
reading loop. Capture, Frame copying, action latency, live changing numbers over time and gameplay
freshness are not established here.
The historical test failures have previously been inspected. Its numbers are regression evidence,
not an untouched holdout estimate. Further generalization needs new, uninspected capture sequences.
Readable targets returning UNKNOWN remain misses. They are not relabeled N/A to inflate accuracy.
